# Changelog

What changed in each version of TankTrouble Color Lab. The release build takes its notes from here: a version's heading
(`## v1.2.3: Title`) becomes the release's title, and the lines under it its notes.

## v1.4.3: Color Lab badges and getting ready for the Chrome Web Store

- 🏷 **Color Lab badges**: the team's badge sits neatly on the tank's corner and right under the name on the forum, and now shows in a tank's profile box too.
- 🛒 **Coming soon to the Chrome Web Store**: one-click install and automatic updates. Once it's there, copies installed from GitHub show how to move over in a few clicks (your looks come with you).

**Also new since v1.4.1:**

- 💾 **Looks**: a Looks button in the garage switches between a tank's saved looks in one click, and **+ New look** starts another.
- ✅ **Clearer saving**: Save shows **✓ Saved** until something changes, and the same look can't be saved twice as a preset.
- 🌙 **Dark** page theme for the site, forum, news and shop.
- 🏆 **Achievements** aren't secret any more: every name and goal shows, and some goals are fairer.
- 🟢 **Online list**: shows who's idle and whether they're in the lobby, a queue or a game. Away or idle for 15+ minutes counts as offline.
- 🕶 **Incognito windows**: Color Lab still works there, but never goes online.
- 🔔 **Update notes** show after an update, and a new extension icon.
- 🔧 **Fixed**: Streetwear sneakers, boombox and hood are easy to see in the garage; the "connecting" text is readable on dark page themes.

## v1.4.2: Saved looks, dark theme & Chrome Web Store ready

- 💾 **Looks**: a Looks button in the garage switches between a tank's saved looks in one click, and **+ New look** starts another. Also in Find in garage > Looks.
- ✅ **Clearer saving**: Save shows **✓ Saved** until something changes, and the same look can't be saved twice as a preset.
- 🌙 **Dark** page theme for the site, forum, news and shop.
- 🏆 **Achievements** aren't secret any more: every name and goal shows, and some goals are fairer. A few very long grinds were retired (kept if you already earned them).
- 🟢 **Online list**: shows who's idle and whether they're in the lobby, a queue or a game. Away (tab in the background in the lobby) or idle for 15+ minutes counts as offline.
- 🕶 **Incognito windows**: Color Lab still works there, but never goes online.
- 🔔 **Update notes** show after an update. Copies from the Chrome Web Store are updated by the store, so they no longer get the GitHub update pop-up.
- 🎨 New extension icon.
- 🔧 **Fixed**: the Streetwear sneakers, boombox and hood are easy to see in the garage; Find in garage draws missing pictures first; the game's "connecting" text is readable on dark page themes.
