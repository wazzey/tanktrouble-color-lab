# Changelog

What changed in each version of TankTrouble Color Lab. The release build takes its notes from here.

## v1.4.2

- 💾 **Looks**: a Looks button in the garage switches between a tank's saved looks in one click, and **+ New look** starts another. Also in Find in garage > Looks.
- ✅ **Clearer saving**: Save shows **✓ Saved** until something changes, and the same look can't be saved twice as a preset.
- 🌙 **Dark** page theme for the site, forum, news and shop.
- 🏆 **Achievements** aren't secret any more: every name and goal shows, and some goals are fairer. A few very long grinds were retired (kept if you already earned them).
- 🟢 **Online list**: shows who's idle and whether they're in the lobby, a queue or a game. Away (tab in the background in the lobby) or idle for 15+ minutes counts as offline.
- 🕶 **Incognito windows**: Color Lab still works there, but never goes online.
- 🔔 **Update notes** show after an update. Copies from the Chrome Web Store are updated by the store, so they no longer get the GitHub update pop-up.
- 🎨 New extension icon.
- 🔧 **Fixed**: the Streetwear sneakers, boombox and hood are easy to see in the garage; Find in garage draws missing pictures first; the game's "connecting" text is readable on dark page themes.
